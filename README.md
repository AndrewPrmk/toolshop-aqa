# Тесты Toolshop AQA

Автоматизированные тесты пользовательского интерфейса и API для практического тестирования программного обеспечения — Toolshop.

## Stack

- Python
- pytest
- Playwright
- requests
- Allure
- Pydantic
- Ruff

Сейчас реализованы UI-тесты на pytest и Playwright. API-тесты и интеграция остальных инструментов будут добавляться по мере развития проекта.

## Запуск тестов

```bash
pytest
```

## Что реализовано

- Настроены проект, виртуальное окружение и запуск тестов через pytest.
- Базовый адрес приложения вынесен в `pytest.ini`.
- Добавлен smoke-тест главной страницы.
- Создан Page Object `HomePage` с локаторами и действиями поиска.
- Добавлена общая фикстура `home_page` в `conftest.py`.
- Реализован тест поиска товара `Combination Pliers`:
  - открытие главной страницы;
  - ввод запроса и запуск поиска;
  - ожидание контейнера результатов с `data-test="search_completed"`;
  - проверка, что найден ровно один товар с ожидаемым названием.
- Добавлен тест поиска несуществующего товара:
  - проверка видимости сообщения об отсутствии результатов;
  - проверка отсутствия названий товаров.
- Добавлен тест сброса поиска:
  - сохранение исходного списка названий товаров;
  - поиск конкретного товара;
  - сброс поиска;
  - проверка восстановления исходного списка;
  - проверка очистки поля поиска.
- Добавлен параметризованный тест поиска по части названия:
  - отдельные запуски для `Pliers` и `Hammer`;
  - ожидание контейнера результатов поиска;
  - проверка наличия хотя бы одного товара;
  - проверка вхождения запроса в каждое найденное название на текущей странице результатов.
- В метод `HomePage.open()` добавлено ожидание видимости первого названия товара исходного каталога.
- Для ожиданий используются проверки Playwright без фиксированных пауз.
- Настроен `.gitignore`.
- Проект опубликован на GitHub.

В файле `test_search.py` четыре тестовые функции дают пять отдельных запусков благодаря параметризации. Вместе со smoke-тестом главной страницы функциональные UI-тесты содержат шесть тестовых случаев.

Дополнительно реализованы пять учебных тестов Playwright: три по контекстам и cookies и два по локаторам.

## Учебные примеры Playwright

В папке `tests/playwright_basics/` находятся упражнения для изучения механизмов Playwright. Они отделены от функциональных тестов Toolshop.

### Контексты и cookies

- Создание дополнительной вкладки в существующем контексте.
- Добавление и чтение cookies.
- Проверка доступности добавленной cookie через контекст второй вкладки.
- Проверка изоляции cookies между разными контекстами.

В этих упражнениях cookies исследуются через API браузерного контекста без перехода на сайт и отправки запросов серверу.

### Локаторы

- Создание локатора до перехода на страницу.
- Проверка видимости поля, ввод текста и проверка его значения.
- Выбор карточки товара через `filter(has=...)` по точному имени заголовка.
- Проверка однозначности выбора карточки.
- Поиск и проверка видимости цены внутри выбранной карточки.

Учебная проверка цены подтверждает видимость элемента, но не корректность суммы.

## Дополнительные команды запуска

Только тесты поиска:

```bash
python -m pytest tests/ui/test_search.py
```

Только тест сброса поиска:

```bash
python -m pytest tests/ui/test_search.py::test_reset_search
```

Параметризованный тест поиска по части названия:

```bash
python -m pytest tests/ui/test_search.py::test_search_by_part_of_name -v
```

UI-тесты с отображением браузера:

```bash
python -m pytest tests/ui --headed
```

Только учебные тесты Playwright:

```bash
python -m pytest tests/playwright_basics/ -v
```

Только учебные тесты локаторов:

```bash
python -m pytest tests/playwright_basics/test_locators.py -v
```

Запуск с сохранением trace для упавших тестов:

```bash
python -m pytest --tracing retain-on-failure
```

Trace помогает исследовать действия, состояния страницы и сетевые события при падении теста.

## Особенности запуска

Тесты работают с публичным демонстрационным приложением и требуют подключения к интернету. Изменения приложения и общих тестовых данных могут влиять на результаты.

Учебные тесты контекстов и cookies не требуют обращения к приложению. Учебные тесты локаторов используют сайт Toolshop.

Ожидание первого товара перед поиском добавлено после наблюдения нестабильных результатов. Пересечение начальной загрузки каталога и поиска рассматривается как возможная причина; точная причина пока не подтверждена.
